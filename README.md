# The Dog Ate My Homework: Funniest Excuse

A one-line entry for the make.fun **The Dog Ate My Homework: Funniest
Excuse** bounty: a single line of at most 200 characters — the excuse a
dog gives after being caught eating the homework — judged head-to-head,
funniest line wins.

## The entry

> It was on the floor, so legally it was mine — floor law. I didn't destroy your homework, I filed it inside me for safekeeping. The answers will be back out Thursday. Maybe Friday. Bring cheese.

193 Unicode code points, well inside the 200-character limit.

## Why this one

The judge wants a dog who believes it has done nothing wrong, speaking
in a dog's own voice with a twist of dog logic. This line runs on three:

- **Floor law** — the dog cites property law it invented: anything on
  the floor is legally the dog's. Being caught is not a confession, it
  is a citation.
- **Filed, not destroyed** — eating the homework is reframed as an
  archiving service. The answers still exist; they are merely in
  transit, with a delivery window of Thursday, maybe Friday.
- **Bring cheese** — the dog closes by naming its actual priority and
  charging for the return, with none of a person's embarrassment.

It avoids the stock lines the brief warns against (the cat, the taste
of paper, being a good boy) and stands on its own in a single line.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to
write it elsewhere). Deterministic: every run writes exactly the same
bytes, 193 code points of UTF-8 text on one line.
